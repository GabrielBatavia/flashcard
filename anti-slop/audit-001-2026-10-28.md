# Audit latihan menulis

Mode: after, dipilih pengguna. Cakupan: fitur handwriting dan jalur masuknya; bukan audit ulang seluruh aplikasi.

## Temuan untuk ditinjau

1. **LOW — Label kartu di editor masih menyebut Flashcard untuk handwriting.** `src/components/DeckEditor.tsx`, bagian badge jenis kartu, hanya membedakan quiz dan flashcard. Data handwriting tetap dipertahankan saat disimpan, tetapi label kurang tepat. Terkait C-1 (kejelasan keputusan antarmuka). Usulan: label Menulis untuk kartu handwriting.
2. **LOW — Navigasi bawah belum memiliki konteks menulis.** `src/components/BottomNav.tsx` hanya memuat Materi, Flashcard, dan Kuis. Pada dek berisi handwriting saja, tombol Flashcard dapat membawa pengguna ke keadaan kosong, meskipun latihan tersedia dari koleksi. Terkait C-3 (kontrol sesuai konteks pengguna). Usulan: tampilkan pintasan Menulis ketika dek aktif memuat kartu handwriting.

Temuan audit tidak diubah otomatis, mengikuti mode after. Implementasi inti sudah tersedia; kedua temuan merupakan penyempurnaan navigasi/label.

## Bukti pemeriksaan

- PASS fungsi inti: impor contoh, pointer drag, urungkan, hapus semua, buka jawaban, Salah, Benar, hasil 1 benar/1 salah, ulang hanya satu soal salah, dan ulang semua diuji di browser lokal.
- PASS perbandingan: satu goresan masih ada di DOM setelah jawaban kalimat `我喜歡喝茶。` dibuka.
- PASS kompatibilitas: skrip tes mencakup bahasa opsional, zh-TW, bahasa Jepang, ekspor/impor multi-dek, jawaban literal, format lama, dan data invalid.
- PASS tampilan: pada viewport 390 x 844 tidak ada overflow horizontal; tema terang dan gelap diperiksa. Jawaban memakai atribut lang zh-TW hanya ketika metadata itu tersedia.
- PASS konsistensi dasar: permukaan, warna teks, dan tombol memakai token aplikasi; garis area tulis berfungsi sebagai panduan baris. Tidak ada aset ilustrasi atau klaim pemasaran baru.
- PASS build: npm run build.
- PASS lint tanpa error; tiga warning lama pada FlashcardViewer (Math.random dan dependency hook) masih ada.
- PASS error browser: tidak ada console error selama alur yang diuji.
- Batas verifikasi: interaksi pointer diuji dengan browser desktop pada viewport HP. Perangkat sentuh fisik, stylus, seluruh kombinasi keyboard, dan semua layar aplikasi belum diaudit.
