# Audit tombol Mode Menulis

Mode: after, mengikuti pilihan sesi pengguna. Cakupan: tombol pengunci scroll pada kartu handwriting.

- Tombol utama memakai aria-pressed untuk menunjukkan status, label menjelaskan kunci scroll, dan kontrol Buka scroll tetap berada di bagian atas viewport saat aktif.
- Warna menggunakan token aplikasi; tidak ada aset atau animasi baru.
- Kunci menyimpan posisi dan style sebelumnya, lalu memulihkannya ketika keluar atau komponen dilepas. Escape dan membuka jawaban juga melepas kunci.
- PASS build: npm run build selesai. PASS whitespace: git diff --check.
- Pemeriksaan ini berdasarkan kode dan build. Verifikasi browser terhalang kegagalan inisialisasi alat browser; pengujian layar sentuh fisik belum dilakukan. Kenyamanan posisi kontrol saat keyboard virtual muncul atau pada layar landscape perlu diverifikasi di perangkat.

Tidak ada temuan baru dari pemeriksaan kode yang memerlukan perubahan visual. Temuan pada audit sebelumnya tetap tercatat terpisah.
