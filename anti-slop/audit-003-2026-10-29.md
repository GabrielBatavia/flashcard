# Audit transisi latihan menulis

Mode after, mengikuti pilihan sesi pengguna. Cakupan: acak soal, transisi penilaian, dan tampilan jawaban handwriting.

- Transisi perpindahan memakai useMotionStep yang sudah digunakan mode belajar lain: keluar 110 ms, masuk 260 ms. Perubahan dikunci selama transisi agar penilaian tidak masuk dua kali.
- Warna batas kartu menunjukkan Benar/Salah; pembukaan jawaban memakai fade dan pergeseran 8 px. Tombol mengecil sedikit saat ditekan sebagai feedback sentuhan.
- Pengacakan dan pengulangan latihan memakai transisi yang sama. Tidak ada animasi berulang atau animasi pada area goresan.
- Reduced motion tetap memakai pemeriksaan JavaScript dan media query global yang sudah ada.
- PASS build: npm run build selesai; PASS whitespace: git diff --check.
- Batas pemeriksaan: berdasarkan kode dan build, belum diuji secara visual pada browser atau perangkat sentuh fisik. Tidak ada temuan baru dari pemeriksaan kode ini; temuan audit sebelumnya tetap tercatat.
